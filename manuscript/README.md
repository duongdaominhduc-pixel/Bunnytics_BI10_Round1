# 📝 Manuscript Directory

Thư mục này được sử dụng để chứa nội dung text/data thô (manuscript) sau khi phân tích xong từng task. 

**Quy trình làm việc:**
1. Người phụ trách phân tích (ví dụ Thành viên A làm Task 2) sau khi xong code/chạy model trên notebook, sẽ viết tóm tắt các phát hiện (findings), con số cụ thể, insights vào file `.md` tương ứng trong thư mục này.
2. Đính kèm cả đường dẫn ảnh (`outputs/figures/...`) nếu cần.
3. Người làm Slide (Thành viên C) sẽ đọc các file `.md` này để tổng hợp, tinh chỉnh câu chữ, và đưa lên Slide proposal cuối cùng.
